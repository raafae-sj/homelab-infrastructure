# Homelab Infrastructure

My personal homelab project built around a Dell OptiPlex 3060 Mini running Proxmox VE.

## Hardware

- Dell OptiPlex 3060 Mini
- Intel Core i5-8500T
- 8GB RAM
- TP-Link TL-SG108E managed switch
- External storage

## Software

- Proxmox VE
- Linux
- SSH
- Tailscale
- Docker
- n8n
- Jellyfin

## Goals

- Learn Linux and server administration
- Learn networking
- Experiment with virtualisation
- Build a personal NAS/media server
- Run automation with n8n
- Build a server monitoring system
- Learn through practical projects
